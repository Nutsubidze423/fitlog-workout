# FitLog Workout

A Next.js PWA workout tracker with exercise database, timer, and progress charts.

## Setup

```bash
npm install
npm run dev
```

## Features

- Exercise database by category
- Rest timer with presets
- Set/rep logging
- Progress charts
- PWA manifest
